# Brand and press

## Approved blurb

Vixl is a local-first, BYOK desktop LLM UI and agent harness for macOS, Windows, and Linux. It includes chat modes, sub-agents, and MCP support. There are no accounts and no cloud service. The app is MIT licensed.
