# Shortcuts and the command palette

Use the command palette when you want to jump to a chat, project, or Settings section without clicking through the sidebar. The full key list is on [Keyboard shortcuts](/reference/keyboard-shortcuts). Settings > General also has a shortcuts dialog; that list is the same app bindings.

`Cmd` or `Ctrl+K` opens the palette, including while you are typing. Open it from sidebar **Search** the same way.

## Command palette

The search field matches projects, chats, and actions. Tabs: **All**, **Agents**, **Actions**, **Settings**.

On **All**, items are grouped as Actions, Projects, Chats, Pinned, and Settings.

- **Actions:** **New Agent**, **Open Settings**, **Open Terminal**, and **Open Editor** (`README.md` when a project is active).
- **Projects:** fleet names.
- **Chats:** titles, with the project name as subtitle.
- **Pinned:** pinned chats.
- **Settings:** General, Graphs, MCP, Providers, Models, LSP, Permissions, Plans, Skills, Agents, Rules.

The **Agents** tab is **New Agent** plus chat and pinned rows. **Actions** is the other actions plus projects. **Settings** is the Settings sections.

**New Agent** (sidebar header or `Cmd` or `Ctrl+N`) goes Home. That shortcut does nothing while you are typing in an input, the editor, or a terminal. The palette shortcut still works.

See [Manage chats](/using/manage-chats) for pin, rename, and the rest of the sidebar.
