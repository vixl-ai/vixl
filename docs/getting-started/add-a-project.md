# Adding a project

A project is a folder you register so chats, MCP, plans, and the workbench use that directory as the workspace. You can skip this and send a [home chat](/concepts/projects-and-home-chats) with **Home**.

## Add a folder

1. Click **Add project** in the Chats toolbar of the left sidebar.
2. Choose the folder in the native picker.

If that folder is already registered, it becomes the active project. Cancel does nothing.

You can also right-click in the Chats section and choose **Open Project**.

Left-click a project to expand its chats. Right-click it and choose **Open Project** for the project page (chats, MCP, graph, plans, skills, agents, and rules). Escape returns home. See [Projects and home chats](/concepts/projects-and-home-chats).

## Remove a project from the sidebar

Right-click the project, then **Remove from sidebar**. That unregisters the folder. It does not delete the folder, its `.vixl` directory, chats, or graph indexes. Graph stores can be deleted later in Settings, Graphs.
