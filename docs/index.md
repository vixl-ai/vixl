# Vixl: the local AI coding agent

Plan, build, and ship with any model. Bring your own key or run one on your machine. No account, no subscription.

- [Download Vixl](https://github.com/vixl-ai/vixl/releases/latest) for macOS (arm64), Windows, and Linux (x64)
- [Read the docs](https://vixl.app/getting-started/index.md)
- [Documentation index for LLMs](https://vixl.app/llms.txt)

Sponsored by [Minds](https://getminds.ai/) and [Niche](https://www.getniche.ai/).

## Coding

Agent mode reads your code, edits files, and runs your tools. Every change lands as a diff you can review, and any turn can be rolled back.

[Learn more about chat modes](https://vixl.app/concepts/chat-modes.md)

## Planning

Create and implement persisted plans that describe your project over time. Save on cost with native agentic orchestration support.

[Learn more about plans](https://vixl.app/using/work-with-plans.md)

## Integrated Editor

A full Monaco editor with LSP support sits next to the chat, so you can read, fix, and review without switching apps.

[Learn more about the workbench](https://vixl.app/using/use-the-workbench.md)

## Terminals

Real terminals open in your project root, right beside the conversation.

[Learn more about terminals](https://vixl.app/using/use-the-workbench.md)

## Local-first by design

- **No account:** No sign-up, no analytics, no Vixl server. Keys stay in your OS keychain.
- **Any model:** Use a provider key you already have, or a local host like Ollama or LM Studio.
- **Lean context:** Progressive tool discovery loads MCP schemas and skills only when the agent asks, so prefills stay small and local models stay fast.
- **Open source:** MIT licensed and free, for macOS, Windows, and Linux.
