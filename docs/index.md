    details: In a worked example, planning once and running implementation on a cheaper sub-agent costs about 70% less than one long full-price chat.
    link: /using/best-practices

    link: /customize/mcp-servers

    details: No Vixl login, no analytics, and no Vixl server. Network calls go to hosts you configure, plus the downloads listed on Privacy.
